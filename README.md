# Automate the Boring Stuff with Python - Exercise Solutions

This repository contains my personal solutions to the practice questions and projects from the book "Automate the Boring Stuff with Python" by Al Sweigart.

## Repository Structure

The project is organized by chapter to make navigation simple.

- ch-01-Python-Basics/
  - hello.py
  - practice_questions.md
- ch-02-Flow-Control/
  - rpsGame.py
  - practice_questions.md
 
## Tech Stack and Requirements

- Language: Python 3.10+
- Libraries: pyinputplus, pyperclip, requests, beautifulsoup4, selenium, openpyxl, PyPDF2, python-docx, csv, json

## Installation and Setup

1. Clone this repository to your local machine:
```
git clone git@github.com:yehudat/automate-the-boring-stuff.git
```
3. Navigate into the project directory:
```
cd automate-the-boring-stuff-solutions
```
5. Install the required third-party libraries:
```
pip install -r requirements.txt
```
